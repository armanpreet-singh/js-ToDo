# JS To-Do App

A clean and responsive To-Do application built with Vanilla JavaScript, HTML, and CSS.

## Features

* Add new tasks
* Edit existing tasks
* Mark tasks as completed
* Delete tasks
* Filter tasks (All / Active / Completed)
* Clear completed tasks
* Local Storage persistence
* Responsive user interface


## Technologies Used

* HTML5
* CSS3
* JavaScript (ES Modules)

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/js-todo.git
```

2. Open the project in VS Code.

3. Run the project using Live Server.
